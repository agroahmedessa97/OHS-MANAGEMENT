# منصة السلامة والصحة المهنية (HSE) متعددة الشركات

منظومة متكاملة لإدارة الشركات، فرق السلامة وصلاحيات كل عضو، السجلات، والتحليل الذكي المرن عبر Cloudflare Worker وقاعدة بيانات D1.

## أبرز المزايا المحدثة
- الحد الأدنى لكلمة المرور 3 أحرف أو أرقام على الأقل.
- إدارة فريق السلامة وتحديد صلاحيات كل عضو بشكل مستقل (المساعد الذكي، السجلات، المستندات، حذف السجلات، إدارة الفريق) مع إمكانية تعديل صلاحيات أي عضو لاحقاً.
- مساعد ذكاء اصطناعي مرن ومفكر يحلل السياق والصور والحوادث والمخاطر بأسلوب عملي منظم.
- ربط الأصول الثابتة (`[assets]`) لتقديم الواجهة والـ API معاً على رابط واحد.

## خطوات التشغيل السريعة
1. ارفع الملفات إلى مستودع GitHub (`OHS-MANAGEMENT`).
2. نفّذ `schema.sql` على قاعدة بيانات D1 (`hse-saas-db` — `7020778ab0a545cbaaa0d1abe3ba4061`).
3. أضف المتغيرات السرية (`JWT_SECRET` و`OPENAI_API_KEY`) في إعدادات Worker (`ohs-management`).
4. انشر المشروع على Cloudflare.

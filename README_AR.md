# منصة السلامة والصحة المهنية (HSE) متعددة الشركات

منظومة متكاملة لإدارة الشركات، فرق السلامة وصلاحيات كل عضو، السجلات، والتحليل الذكي المرن عبر Cloudflare Worker وقاعدة بيانات D1.

## أبرز التحسينات في هذه النسخة المستقرة
- تهيئة الجداول والفهارس تلقائياً في D1 عند الحاجة (`ensureDatabaseReady`) لتفادي أي خطأ في الخادم حتى لو نُسي تشغيل `schema.sql` يدوياً.
- فحص مسبق لتكرار البريد الإلكتروني واسم المستخدم وإرجاع رسائل واضحة بالعربية مع إظهار تفاصيل الخطأ إن وُجد.
- التحقق المسبق من صلاحية الجلسة (JWT) عند فتح الصفحة لمنع أخطاء 401 المفاجئة.
- دقة مسار حذف السجلات وإرجاع 404 عند عدم وجود السجل.
- حذف تحذير `ignore` من `wrangler.toml` وتوحيد النطاق الفعلي `https://ohs-management.ahmed4qhse.workers.dev`.
- تفعيل زر "قريباً / قيد الربط" للوحدات الفرعية غير المرفوعة بعد بدلاً من الروابط المكسورة (404).

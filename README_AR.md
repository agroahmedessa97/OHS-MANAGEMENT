# منصة السلامة والصحة المهنية (HSE) متعددة الشركات

منظومة متكاملة لإدارة الشركات، فرق السلامة، السجلات، والتحليل الذكي للمخاطر عبر Cloudflare Worker وقاعدة بيانات D1.

## الملفات المضمنة
- `index.html`: واجهة المنصة الرئيسية المربوطة تلقائياً بالخادم دون إظهار إعدادات API للمستخدم.
- `worker.js`: كود الخادم الخلفي على Cloudflare Workers لإدارة الشركات والمستخدمين والصلاحيات والسجلات والتحليل الذكي.
- `schema.sql`: مخطط قاعدة بيانات Cloudflare D1.
- `wrangler.toml`: إعدادات نشر المشروع وربط قاعدة البيانات D1.
- `AI_SYSTEM_PROMPT_AR.txt`: التعليمات التخصصية لمساعد السلامة والصحة المهنية.

## خطوات التشغيل السريعة على Cloudflare
1. أنشئ قاعدة بيانات D1 باسم `hse-saas-db` وانسخ `database_id` إلى `wrangler.toml`.
2. نفّذ محتوى `schema.sql` على قاعدة D1.
3. أضف المتغيرات والأسرار (`JWT_SECRET` و`OPENAI_API_KEY`) في إعدادات المشروع على Cloudflare.
4. انشر المشروع وافتح رابط `https://ohs-management.agroahmedessa97.workers.dev`.
